# Link Vault

A React-based application for managing and organizing useful links in one place.

## Tech Stack & Libraries

The following libraries are used in this project:

| Library | Purpose in Link Vault |
|---|---|
| **React** | Building the user interface using reusable components. |
| **react-router-dom** | Managing navigation between application pages, such as Register, Verification, and Dashboard. |
| **Axios** | Handling HTTP requests to communicate with the backend API, such as fetching, adding, and managing saved links. |
| **Zustand** | Managing shared application state, such as user information and saved links, across different components. |
| **Formik** | Managing form state and handling user input in forms such as registration and authentication. |
| **Yup** | Validating form data, including email addresses and passwords, before submission. |
| **Tailwind CSS** | Styling the application using utility classes and a centralized design system. |
| **React Icons** *(Optional)* | Providing reusable icons for navigation, actions, and interface elements. |

## Design System

The project uses centralized design tokens to maintain consistent styling across the application.

These tokens include:
- Colors
- Spacing
- Font sizes
- Border radius
- Other reusable design values
